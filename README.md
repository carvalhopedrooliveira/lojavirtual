# Loja Virtual

- Comandos

- git clone https://github.com/carvalhopedrooliveira/lojavirtual.git
- git remote -v
- git branch
- git log --oneline
- git status
- git commit -m "Aqui a descrição da alteração"
- git push origin
- git pull
- git tag -l -> lista as tags
- git tag v-0.0.0.1 4826db9 -> cria uma tag
- git diff 99d61e6 v-0.0.0.1
- git branch developer - criar uma branch
- git branch - lista as branchs
- git switch developer - muda de branch
